# FORKNIGHT Provenance and Project Protection

FORKNIGHT protects its work through verifiable authorship and controlled
authority, not secrecy claims that a public repository cannot enforce.

- Every upstream is recorded by canonical URL, license scope, and immutable
  commit SHA.
- Every registry entry receives a deterministic SHA-256 provenance hash.
- Every promoted adapter retains upstream notices and a Mongoose contract.
- Every build result is attached to an append-only event and merge commit.
- Public discovery data contains no credentials, signing keys, private model
  prompts, or command tokens.
- Robot command networks stay separate from public websites.
- Signed commands, branch protection, review gates, and deployment secrets
  control operational access.

The /k, /z, Octave, and other custom formats remain preserved. A writer may
link or index them but cannot delete or replace them without explicit scope.
