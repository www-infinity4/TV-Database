# FORKNIGHT Build Creation Zones

Zones are stable Mongoose interfaces, not copies of entire upstream projects.
Each zone selects a small adapter from the immutable repository registry.

| Zone | Purpose | Initial upstreams |
| --- | --- | --- |
| Game Simulation | Incremental loops, resource state, visible telemetry | open-source-games, Awesome-Gamedev, 0xVenture-Capitalist |
| Model and Orchestration | LLM execution, provider routing, stateful plans | llama.cpp, Ollama, LiteLLM, LangGraph |
| Readers and Research | Documents, retrieval, indexing, evidence | MarkItDown, Haystack, RAGFlow, Qdrant |
| Writers and Coders | Proposed patches and isolated software-agent work | Aider, OpenHands, MCP Python SDK |
| Voice and Validation | Speech input, browser tests, security quarantine | whisper.cpp, Playwright, Trivy |

The Crown Index stores public provenance. Operational authority is separate:
signed commands, protected credentials, allowlisted adapters, immutable pins,
and append-only results. Obscure formats are never treated as security.
