# Writers and Coders Zone

This zone turns a reviewed intent into a minimal patch. Aider and OpenHands are
reference implementations; MCP supplies the proposed tool boundary.

Required sequence: issue scope, isolated branch, explicit files, tests,
security scan, PR, owner policy, merge verification, and Crown re-index.

No writer may silently overwrite unique /k, /z, Octave, custom indexes, or
meaningful existing files.
